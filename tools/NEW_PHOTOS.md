# 새 사진 올리기 / Claude 작업 순서

사용자가 "새 사진 올려 줘", "사진 아카이브해 줘", `/new-photos` 처럼 요청하면 이 순서를 따릅니다.
사용자는 Google Drive `공공디자인 사례 연구/_새 사진` 폴더에 사진만 넣어 둡니다. 하위 폴더 이름과 파일명은 사용자가 남긴 메모일 수 있습니다.

- 기본은 **바로 공개**입니다. 사용자가 "확인 후 올려"라고 하면 4단계 뒤에 표를 보여 주고 승인을 받은 다음 5단계로 갑니다.
- 명령의 `python` 은 맥에서는 `python3`, 윈도우에서는 `python` 입니다.
- 저장소 위치: 맥 `~/github/public-design-archive`, 윈도우 `C:\Users\ARMULA\github\public-design-archive`

## 1. 최신으로 받기

```
cd ~/github/public-design-archive
git pull --rebase --autostash
```

## 2. 새 사진 찾기

```
python tools/inbox.py scan
```

- 새 사진이 0장이면 그렇게 알리고 끝냅니다. 이미 있는 사진(중복)과 건너뛴 파일(동영상 등)도 함께 알려 줍니다.
- 결과: `_work/inbox/sheet_NN.jpg` (밀착 인화, 사진마다 id와 촬영일), `_work/inbox/thumbs/<id>.jpg`, `_work/inbox/pending.json`

## 3. 사진 보기

- `_work/inbox/sheet_*.jpg` 를 모두 Read 합니다. 애매한 사진은 `_work/inbox/thumbs/<id>.jpg` 를 크게 봅니다.
- `pending.json` 의 `folder`, `filename` 은 사용자 메모일 수 있으니 참고합니다 (예: 폴더 `안전색채`, 파일명 `뉴욕 쓰레기통`). 카메라가 붙인 이름(20261011_123456, IMG_1234, KakaoTalk_...)은 무시합니다.
- `near` 가 있으면 이미 사이트에 있는 사진과 비슷하다는 뜻입니다. `img/t/<기존 id>.jpg` 와 비교해 같은 장면이면 `exclude` 로 둡니다.

## 4. decisions.json 쓰기

`_work/inbox/decisions.json` 에 모든 id의 결정을 씁니다.

```json
[
  {"id": "p0888", "type": "color", "caption": "기둥 모서리를 알리는 노란 안전 도색", "quality": 2},
  {"id": "p0889", "type": "exclude", "caption": "흐린 사진", "quality": 1}
]
```

### type

| key | 유형 | 기준 |
|---|---|---|
| walk | 보행과 횡단 | 보도, 건널목, 횡단보도, 교차로, 속도저감 노면, shared space, 스쿨존 보행로, 계단과 경사로 같은 보행 동선 |
| color | 안전색채 | 안전색, 노란 기둥, 교각과 교량 색채, 단차 색채, 휀스 색채, 주차장 기둥 안전 도색, 노란버스처럼 색으로 위험을 알리는 디자인 |
| sign | 사인과 정보 | 안내사인, 지하철 사인, 바닥 정보, 주차장 그래픽과 번호, 출구 유도, 픽토그램, 노선도, 지도 |
| bike | 자전거 | 자전거도로, 거치대, 자전거 신호, 자전거 편의시설 |
| cpted | 범죄예방 | 영역성, 자연감시, 접근통제, 골목 안심 조명과 벽화, 안심 귀갓길, 비상벨 |
| furniture | 공공시설물 | 벤치, 쉘터, 버스정류장, 쓰레기통, 볼라드, 맨홀, 트렌치, 그늘막, 화장실, 가로등, 펜스의 형태 |
| inclusive | 배려와 유니버설 | 휠체어, 노인, 어린이, 임산부, 점자블록, 엘리베이터, 경사로, 수유실, 배려 벤치처럼 모두를 위한 디자인 |
| nudge | 넛지와 행동유도 | 재미나 단서로 행동을 바꾸는 디자인, 쓰레기통 넛지, 대기선, 금연 유도 |
| play | 놀이와 활력 | 어반 플레이, 놀이터, 파클렛, 포켓파크, 교각 하부 활용, 광장 이벤트, 미끄럼틀, 그네, 도시 숲 |
| street | 가로와 경관 | 거리 풍경, 건축과 공공공간, 랜드마크, 전망대, 휴게소, 공원 풍경, 야경, 해외 도시 장면 |
| memory | 기록 | 1960~90년대 옛 사진, 옛 공공시설물, 역사적 장면 |
| exclude | 숨김 | 흐리거나 의미 없는 사진, 개인 사진(셀카, 식사, 얼굴이 크게 나온 사람), 문서와 화면 캡처, 거의 같은 사진의 반복 (가장 좋은 1장만 남김) |
| skip | 보류 | 이번에는 처리하지 않고 `_새 사진` 에 그대로 둡니다 (사용자에게 물어볼 사진) |

### caption

- 8~25자 한국어 명사구로, 디자인이 하는 일이나 장면을 씁니다. 예: "보행자 동선을 이어 주는 붉은 자전거길", "1968년 서울역 앞 풍경"
- 장소 이름은 메모, 파일명, 사진 속 글자로 확실할 때만 넣습니다 (예: 뉴욕, 히로시마, 서울역).
- 중간점(·)은 쓰지 않습니다. 같은 종류 나열은 `, `, 성격이 다른 정보는 ` / `.
- 번호를 붙이지 않습니다.

### quality

3 = 표지에 쓸 만큼 인상적인 사진, 2 = 좋은 사진, 1 = 쓸 수는 있지만 약한 사진. 유형 안에서 3, 2, 1 순으로 앞에 놓입니다.

## 5. 반영

```
python tools/inbox.py apply
```

사진을 `현장 사진/연-월` 폴더로 옮기고(중복은 `현장 사진/_중복`), `data/catalog.json` 에 더한 뒤 빌드합니다. 웹용 사진에서는 위치정보(GPS)를 포함한 EXIF가 모두 지워집니다.

## 6. 올리기

```
sh tools/sync.sh "새 사진 N장"                                        # 맥
powershell -ExecutionPolicy Bypass -File tools\sync.ps1 "새 사진 N장"   # 윈도우
```
